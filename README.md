## Calculadora Básica

- Sobre o projeto

Projeto desenvolvido como exercício introdutório de lógica de programação, utilizando HTML e JavaScript.

A calculadora solicita valores e uma operação matemática, permitindo praticar a realização de cálculos por meio de código.

- Tecnologias utilizadas

* HTML
* JavaScript

- Funcionalidades

* Entrada de valores pelo usuário.
* Seleção de operações matemáticas.
* Realização de cálculos.
* Exibição do resultado conforme a implementação do programa.

- Objetivo do projeto

Praticar conceitos fundamentais de programação, como variáveis, entrada de dados, operadores matemáticos e estruturas condicionais.

- Aprendizados

Este projeto faz parte dos meus primeiros exercícios de programação e representa uma etapa inicial do meu aprendizado em JavaScript.
